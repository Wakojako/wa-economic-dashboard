# Setup checklist

- [ ] Extract ZIP to a normal folder
- [ ] Install R
- [ ] Install RStudio Desktop
- [ ] Install Quarto
- [ ] Open `WA-Economic-Dashboard.Rproj`
- [ ] Run `source("setup.R")`
- [ ] Run `source("run_dashboard.R")`
- [ ] Open `_site/index.html`
- [ ] Check the seven headline rows
- [ ] Check the three ABS detail tables
- [ ] Decide whether to configure automatic FuelWatch monthly averages
- [ ] Upload project to GitHub
- [ ] Enable GitHub Pages using GitHub Actions
